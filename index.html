⚽ Tracker de Pronósticos — Mundial 2026

Esta página muestra los pronósticos de la fase de grupos del Mundial 2026 junto con los resultados reales del torneo en tiempo (casi) real.

Datos de resultados: Los resultados reales se obtienen de la API pública de openfootball/worldcup.json alojada en GitHub. No requiere API key y se actualiza durante el torneo.

Pronósticos: Exportados desde Excel. Incluye los 72 partidos de la fase de grupos, la clasificación final prevista y el máximo goleador.

Sistema de puntuación:

  • 🟢 Resultado exacto — marcador exacto correcto
  • 🟡 Signo correcto — acierta ganador o empate, falla marcador
  • 🔴 Incorrecto — resultado equivocado
API: github.com/openfootball/worldcup.json Sin API Key · Open Source
